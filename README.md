# Veridic

## Instalação

### macOS / Linux
```bash
git clone https://github.com/Andre-PI/veridic
cd veridic
chmod +x setup.sh
./setup.sh
```

### Windows
```bat
git clone https://github.com/Andre-PI/veridic
cd veridic
setup.bat
```

## Iniciar

```bash
source venv/bin/activate      # macOS/Linux
venv\Scripts\activate         # Windows

streamlit run app.py
```

## Requisitos

- Python 3.9+
- ffmpeg (opcional)
